**🌍 World Countries Data**

World Countries Data is an interactive web application that provides information about countries around the world. Users can search, filter, and visualize country data, including population, capital, languages, region, and area.

**🚀 Features**

**Search:** Filter countries by name, capital, or language.

**Sort & Filter:** Sort countries by name, capital, or population.

**Favorites / Highlights:** Easily explore top countries based on population.

**Interactive Charts:** Visualize the top 10 most populated countries using Chart.js.

**Responsive Layout:** Works on desktops and mobile devices.

**Clean UI:** Simple and intuitive interface with hover effects and visual cues.

- HTML5

- CSS3 / Flexbox

- JavaScript (ES6+)

- Chart.js – For interactive population charts

- Font Awesome – Icons

- Country Dataset – JSON data for 250+ countries

💻 Installation & Setup

1. Clone the repository:

    git clone <your-repo-link>


2. Navigate to the project folder:

    cd world-countries-data


3. Open index.html in your browser.

    No additional dependencies are required; it works entirely in the browser.

**📝 Usage**

**Search Countries:** Type a country name, capital, or language in the search bar.

**Filter by Buttons:** Click NAME, CAPITAL, or POPULATION to filter results.

**View Chart:** Click the 📊 graph icon to see a bar chart of the top 10 countries by population.

**Explore Details:** Each country card shows flag, capital, languages, population, region, and area.
